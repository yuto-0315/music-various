# おとあて

耳とリズム感をためす、小さな音楽ゲーム集。ビルド不要の静的サイトなので、GitHub Pages にそのまま載せられます。

| No. | ゲーム | 内容 |
|:--|:--|:--|
| 01 | 周波数あて | 目盛りのないスライダーで 440 Hz / 442 Hz の正弦波を探す |
| 02 | 高いのはどっち？ | 2音の高低を聞き分け。正解するたびに差が縮む（3ミスで終了） |
| 03 | 耳年齢チェック | 高音から下がっていく音が聞こえた周波数で、耳年齢の目安を出す |
| 04 | ドレミあて | 鳴った音を鍵盤で答える（白鍵のみ／12音） |
| 05 | 明るい？暗い？ | 和音のメジャー／マイナーを聞き分け |
| 06 | 音色あて | 正弦波・三角波・矩形波・のこぎり波を聞き分け |
| 07 | 音程あて | 2音の音程（長3度・完全5度など）を当てる（3択／7択／12択） |
| 08 | BPMあて | クリックのテンポを当てる |
| 09 | テンポキープ | 指定テンポで音なしタップ。平均テンポとゆれを表示 |
| 10 | ジャストタイミング | クリックに合わせてタップ。ずれをミリ秒で測る |
| 11 | メロディ記憶 | 1音ずつ長くなるメロディをまねする |
| 12 | リズムコピー | お手本のリズムを1小節聞いて、タップで再現（全4ラウンド） |
| 13 | この音、歌える？ | お手本と同じ高さを声で出す。チューナー表示つき（マイク使用） |
| 14 | 音域チェック | いちばん低い声と高い声を測って音域を出す（マイク使用） |

マイクを使うゲームは、声をこの端末の中で解析するだけで、録音や送信はしません。GitHub Pages は HTTPS なので、そのままマイクを使えます。

結果は「結果を画像で保存」で共有用の PNG（1200×630）として保存できます。スマホでは「共有」から直接 SNS などに送れます。

## 公開のしかた（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」にする
3. Branch で公開したいブランチと `/ (root)` を選んで **Save**

数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。`#pitch` のようにゲームIDを付けると、そのゲームを直接開けます。

## ローカルで動かす

ES Modules を使っているため、ファイルを直接開くのではなくローカルサーバー経由で開いてください。

```bash
python3 -m http.server 8000
```

## 構成

```
index.html        画面（ゲーム一覧と各ゲーム）
style.css         見た目
js/main.js        画面切り替え（URLのハッシュで切り替え）
js/audio.js       Web Audio まわり（正弦波・単音・メトロノーム）
js/mic.js         マイク入力と声の高さの推定（自己相関）
js/music.js       音名・周波数の変換
js/quiz.js        「聞いて選ぶ」10問クイズの共通部分
js/result.js      結果表示・ランク判定
js/share-card.js  共有画像の描画・保存・共有
js/<ゲームID>.js  各ゲーム
```
